# Environment XML → shader constants

Source: reflection of all dx11 `.fxc` in `data.pack` (`shaders/cbuffers.txt`, produced by `fxc_dump`) and
the attribute schema of every `.environment` / `.lighting` (`xml_schema.tsv`, produced by `xml_roundtrip`).

Status:
- **name** — the CB variable name matches the attribute; the transform is still to be confirmed against a capture.
- **RE** — the engine derives the value; needs disassembly of `empire.retail.dll` or a capture.
- **verified** — confirmed against a capture or the disassembly.

The transforms verified since this first mapping are in docs/re/renderer.md ("Engine-side transforms", "Verified against a memory
dump", "Battle fog") and in the code that applies them (`wce_render` `environment_apply.rs`, `wce_scene` `environment.rs`).

## CLOUD_PLANE_MESH → `cloud_plane_PS` (80 B) / `cloud_plane_VS` (16 B)

| CB variable | From | Status |
| --- | --- | --- |
| `g_sun_transmitted_colour`, `g_sun_reflected_colour` | same-named | name |
| `g_transmit_falloff` | `sun_transmit_falloff` | name |
| `g_flatten_factor`, `g_horizon_alpha_start/end` | same-named | name |
| `g_cloud_shadow_colour/falloff` | same-named (`cloud_shadow_gradient` → shading CBs) | name |

Geometry is generated by the engine from `grid_size`, `height_scale`, `cloud_density`, `cloud_height_variation`, `cloud_rotation`,
`cloud_velocity`, the `CLOUD`/`CLOUD_ELEMENT` sprite placements (`texture_row/column/index` into the `cloudset` atlas) and `probability`.
Rebuilt from the DLL (docs/re/renderer.md, "Clouds"; `wce_scene` `clouds.rs`); the drift was decoded 2026-10-28.

## SUN_MESH → `sun_VS` (`g_sun_scale`) + `sun.hlsl` PS (`sun_flare`, `sun_occlusion`)

## POST_PROCESSING, DEPTH_OF_FIELD → `hdr_to_screen_PS` (1952 B)
- `colour_matrix` (float4x4): built by the engine from `brightness_*`, `contrast_*`, `saturation_*`, `hue` and `overlay`: verified
  (fn 0x172c100; `wce_scene::environment::colour_matrix`).
- `focus_distance`, `focal_length`, `blur_kernel_scale`: from `DOF_focus` `variance(a,b)`, `DOF_blur_size`, `use_DOF`: verified
  (docs/re/renderer.md, "Depth of field").
- `colorimetry_VS_PS`: `g_brightness`, `g_gamma_output` come from user graphics settings, not from weather.

## WEATHER → `weather_shared` (32 B), `wind_VS` / `wind_PS`
- `g_snowing_intensity` ← `snowing_intensity`; `g_weather_type`, `g_season_type`, `g_snow_mask`: engine. `g_season_type` (summer 1,
  winter 3) is read by no shader, vanilla or TDD (2026-10-31).
- `g_wind`, `g_wind_offset`, `wind_direction`, `gust_start_time`, `wind_vegetation_*`: simulated from `weather_definitions.xml`
  (`WEATHER_DEFINITION` gust parameters) + `wind_dir_random`: solved (docs/re/particles.md, "Wind").
