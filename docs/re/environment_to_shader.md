# Environment XML → shader constants

Source: reflection of all dx11 `.fxc` in `data.pack` (`shaders/cbuffers.txt`, produced by `fxc_dump`) and
the attribute schema of every `.environment` / `.lighting` (`xml_schema.tsv`, produced by `xml_roundtrip`).

Status:
- **name** — the CB variable name matches the attribute; the transform is still to be confirmed against a capture.
- **RE** — the engine derives the value; needs disassembly of `empire.retail.dll` or a capture.
- **verified** — confirmed against a capture or the disassembly.

## POST_PROCESSING, DEPTH_OF_FIELD → `hdr_to_screen_PS` (1952 B)
- `colour_matrix` (float4x4): built by the engine from `brightness_*`, `contrast_*`, `saturation_*`, `hue` and `overlay` → **RE (key item)**.
- `focus_distance`, `focal_length`, `blur_kernel_scale`: from `DOF_focus` `variance(a,b)`, `DOF_blur_size`, `use_DOF` → RE.
- `colorimetry_VS_PS`: `g_brightness`, `g_gamma_output` come from user graphics settings, not from weather.

## WEATHER → `weather_shared` (32 B), `wind_VS` / `wind_PS`
- `g_snowing_intensity` ← `snowing_intensity`; `g_weather_type`, `g_season_type`, `g_snow_mask`: engine. `g_season_type` (summer 1,
  winter 3) is read by no shader, vanilla or TDD (2026-10-31).
- `g_wind`, `g_wind_offset`, `wind_direction`, `gust_start_time`, `wind_vegetation_*`: simulated from `weather_definitions.xml` (`WEATHER_DEFINITION` gust parameters) + `wind_dir_random`: RE.
